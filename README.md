# IC2k23 Kalpana AI Lab Assignment

This project contains a lab-wise AI assignment organized according to the suggested mapping provided in the course plan.

## Lab-wise Mapping

| Lab | Experiment |
| --- | --- |
| Lab 1 | AI Environment Setup, Production Systems, Water Jug Problem |
| Lab 2 | BFS, DFS, Hill Climbing, Best First Search, A* |
| Lab 3 | Data Preprocessing, EDA, NumPy, Pandas, Visualization |
| Lab 4 | Knowledge Representation, Rule-Based Systems, Semantic Networks |
| Lab 5 | Decision Tree Classifier, Model Evaluation |
| Lab 6 | PyTorch Basics, Linear Regression, Neural Network Fundamentals |
| Lab 7 | Explainable AI (Grad-CAM), Adversarial AI (FGSM), PCA/SVD, Mini Project |

## Project Structure

- `water_jug_problem/` - C implementation of the water jug problem
- `Lab_1_AI_Environment_Setup/` - Python environment check and setup demo
- `Lab_2_BFS_DFS/` - BFS, DFS, and search algorithm examples
- `Lab_3_Data_Preprocessing/` - Data cleaning and preprocessing demo
- `Lab_4_Knowledge_Representation/` - Rule-based expert system demo
- `Lab_5_Decision_Tree/` - Decision tree classifier implementation
- `Lab_6_PyTorch_Basics/` - Linear regression with PyTorch
- `Lab_7_Explainable_AI/` - Explainable AI demonstration

## How to run

Python labs can be run with:

```bash
python path/to/script.py
```

The water jug problem is a C program and can be compiled with:

```bash
gcc water_jug_problem.c -o water_jug_problem
./water_jug_problem
```

## Notes

These implementations are designed for learning and coursework demonstration. You can extend them with real datasets, notebooks, or a final mini-project according to your course requirements.
